# CIS2321-Systems-Analysis
CIS2321 Systems Analysis Portfolio


Project Overview

This repository contains my SDLC Project – Sideways Elevator Panel. It demonstrates how a system moves through the Systems Development Life Cycle from initial planning and requirements gathering to system design.

Role of a Systems Analyst

A systems analyst bridges the gap between business needs and information technology. They study how an organization works, gather requirements from users, and design technical solutions to solve business problems efficiently.

Importance of CASE Tools

Computer-Aided Software Engineering (CASE) tools are essential because they help analysts plan, diagram, and document complex systems quickly and accurately. Using these tools reduces human error, keeps project documentation consistent, and makes it easier for teams to collaborate.

Course Reflection

Taking this Systems Analysis course has been very valuable for my degree and future career in technology. Learning how to break down a problem using the SDLC and design clear system models gave me practical, real-world skills.
